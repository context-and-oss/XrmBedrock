# Web resources

This project builds two kinds of Dataverse web resources into `dist/`:

- `src/html/<name>/` contains `index.html`, `main.ts`, and `styles.css`. Each folder becomes one
  self-contained `<name>.html`; TypeScript, CSS, images, and fonts are embedded in that file.
- `src/forms/<name>.ts` contains form event handlers. Each file becomes `forms/<name>.js` and is
  exposed as `templatecompanyname.templateprojectname.FormScripts.<Name>`.

Both kinds are type-checked against the files generated by XrmDefinitelyTyped in `typings/`. HTML
resources can import `@delegateas/xrmquery` and use the generated `XDT` Web API model. Form scripts
can use the generated `Form.<table>.<type>.<form>` declarations and the normal `Xrm` client API.

From this directory:

```bash
npm run typings    # regenerate form + Web API typings from Dataverse
npm run dev        # build, synchronize, and watch both source trees
npm run typecheck
npm run build      # writes dist/*.html and dist/forms/*.js
npm run watch
npm run deploy     # build and synchronize through the root XrmSync profile
```

To add an HTML resource, copy `src/html/sample`. To add a form script, copy
`src/forms/sample.ts`. XrmSync uploads paths below `dist/` into the configured solution and never
deletes remote resources (`NoDelete` is enabled in the root `appsettings.json`).
